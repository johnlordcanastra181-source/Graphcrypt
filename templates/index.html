About GraphCrypt v1.0

Precision Algorithm Engine: Weighted A* & Caesar Cipher

GraphCrypt v1.0 integrates weighted pathfinding with numeric cryptography into a unified end-to-end analytical workflow.

Workflow Sequence:
  1. Weighted Graph: Build or edit nodes and weighted edges on the interactive canvas.
  2. A* Pathfinding: Find the optimal route with heuristic functions: \(f(n) = g(n) + h(n)\).
  3. Shortest Path: Compute the exact minimal sum of original numerical edge weights.
  4. Encrypt Edge Weights: Shift edge weights using numeric Modulo-10 Caesar cipher: \((d + \text{shift}) \pmod{10}\).
  5. Generate TXT & Export: Inspect formatted output and download genuine encrypted_edge_weights.txt.
