About the Final Project System

BOHOL ISLAND STATE UNIVERSITY

Office of the College of Science and Management · Poblacion Norte, Clarin, Bohol

Balance | Integrity | Stewardship | Uprightness

Title: Intelligent Text Search, Compression, and Optimization System

This comprehensive algorithmic platform satisfies all requirements of the Course Syllabus (F-AQA-INS-002) alongside the precision GraphCrypt weighted pathfinding and cryptography engine.

Required Syllabus Features Implemented:
  1. Text Input / Dataset: Interactive corpus editor, .txt file upload, and pre-loaded sample datasets (Literature, Genomic DNA, Server logs, Repetitive sequences).
  2. Pattern Matching: Full implementations of Knuth-Morris-Pratt (KMP), Boyer-Moore, Rabin-Karp, Brute Force, and Approximate (Levenshtein) with live highlight visualizers and comparison telemetry.
  3. Text Compression: Huffman Coding (with prefix binary tree & codebook), Run-Length Encoding (RLE), and LZW Dictionary Compression with original/compressed sizes, compression ratios, space savings, and lossless verification.
  4. Optimization Feature: Genetic Algorithm (GA) metaheuristic with generation-by-generation fitness convergence charts, and Combinatorial 0/1 Knapsack (Dynamic Programming exact vs Greedy).
  5. Parallel or Randomized Algorithms: Multi-threaded parallel pattern search across thread worker pools with speedup telemetry, Randomized QuickSort (random pivot to guarantee expected \(O(n \log n)\)), and Randomized QuickSelect.
  6. Performance Analysis: Rigorous Big-O Time & Space Complexity matrix with theoretical proofs and live empirical benchmarking.
  7. Graph Precision Engine: Interactive SVG graph canvas, Weighted A* pathfinding, and Modulo-10 Caesar cipher cryptography.
